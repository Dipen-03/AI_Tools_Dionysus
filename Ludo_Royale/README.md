# Ludo Royale

A graphical Ludo game developed using Python and Pygame.

## Features
- Colorful Ludo board
- Single-player and multiplayer modes
- Animated dice
- Token movement and capturing
- Safe squares and winning rules

## Requirements
- Python 3.9+
- Pygame

## Installation
pip install pygame

## Run the Game
python3 ludo_royale.py

## Controls
- Space: Roll dice
- Mouse: Move tokens
- R: Restart
- Esc: Main menu

## Technologies
Python, Pygame, VS Code
